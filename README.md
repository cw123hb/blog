# Myriad Leaves

This blog publishes from the `main` branch with GitHub Pages. The `posts.json`
archive is generated by Jekyll on each commit.

## Write or edit a post in GitHub

1. Open the `posts` folder in this repository.
2. Edit an existing `.md` file, or choose **Add file → Create new file** and name
   it `posts/your-post-name.md`.
3. Start a new file with YAML front matter, then write in Markdown:

   ```markdown
   ---
   title: "Your post title"
   date: "2026-09-28"
   slug: "your-post-name"
   tags: []
   description: ""
   ---

   Your post text goes here.
   ```

4. Commit the change to `main`. GitHub Pages will rebuild the site and archive.

The file name becomes the post URL and archive route. Use the same file name when
editing a post so existing links keep working.
