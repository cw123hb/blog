# Myriad Leaves

This blog publishes from the `main` branch with GitHub Pages. The `posts.json`
archive is generated by Jekyll on each commit.

`_config.yml` sets `layout: null` for everything in `posts/`. GitHub Pages
bundles the `jekyll-default-layout` plugin, which would otherwise wrap each post
in the default theme layout and add a link to the site title ("blog") plus the
theme stylesheet to the top of every post. Posts must stay bare HTML fragments,
because `index.html` fetches them and injects them into the page.

## Preview locally

`posts.json` and the `posts/*.html` pages only exist after GitHub Pages builds
the site. Opening `index.html` directly, or serving the folder with a plain
static server, therefore shows "Could not load posts". Use the preview script
instead:

1. Run `uv run preview.py`.
2. Open <http://127.0.0.1:4000>.

The script writes a throwaway copy of the built site into `_site/` (already
gitignored) and serves it. `uv run preview.py --build-only` only builds it.

## Write and publish from the command line

`./blog` is a small helper for the post workflow.

1. `./blog create my-post-name` copies `_templates/post.md` to
   `posts/my-post-name.md`, fills in today's date and the slug, and opens it in
   `micro` (or `nano`). Run `./blog create` with no name to be prompted.
2. Edit the title, description and body, then save the file.
3. `./blog publish` builds a local copy to check for errors, commits the change
   with the message `Add my-post-name.md`, and pushes to `main`.

`./blog` with no command shows a menu. GitHub Pages takes a few minutes to
rebuild after a push.

## Write or edit a post in GitHub

1. Open the `posts` folder in this repository.
2. Edit an existing `.md` file, or copy [`_templates/post.md`](_templates/post.md)
   into `posts/your-post-name.md`.
3. Replace the template title, date (`YYYY-MM-DD`), slug, description, and body.
   Use the file name without `.md` as the slug.
4. Commit the change to `main`. GitHub Pages will rebuild the site and archive.

The file name becomes the post URL and archive route. Use the same file name when
editing a post so existing links keep working.
